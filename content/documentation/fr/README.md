# Installer et configurer KraftInk

Ces guides vous accompagnent pour mettre votre site en ligne, connecter vos services et le garder en état de marche. Pour gérer les pages, les membres ou l’apparence, utilisez les formulaires et les explications du panneau.

## Votre première installation

1. [Préparez l’hébergement et installez KraftInk](installation.md).
2. [Vérifiez le domaine, HTTPS et les e-mails](configuration.md).
3. [Ajoutez les plugins et le thème dont vous avez besoin](extensions-catalogue.md).
4. [Mettez en place le cron et les sauvegardes](operations.md).

Vous avez déjà un site ? Le [guide d’import](migration.md) explique comment reprendre ses données.

## Connecter vos services

- **Serveur de jeu** : [choisir la connexion adaptée](games.md), puis [installer KraftLink](kraftlink.md) si nécessaire.
- **Comptes externes** : [configurer Google, Discord ou un autre fournisseur](oauth.md). Les [rôles liés Discord](discord-linked-roles.md) ont leur propre procédure.
- **Bots et services externes** : [créer un compte technique et ses jetons](service-accounts.md) depuis l’administration.
- **Boutique et votes** : [préparer les paiements et les livraisons](shop-administration.md), ou [relier un site de vote](vote.md).

## Garder le site opérationnel

Consultez les [mises à jour](updates.md), les [sauvegardes et le dépannage](operations.md), ou les [questions fréquentes](faq.md).

## Créer une extension

Vous écrivez du code pour KraftInk ? Le [parcours développeur](developpeurs.md) couvre les plugins, thèmes, modules de jeu et API.
