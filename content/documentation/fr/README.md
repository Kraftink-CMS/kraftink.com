# Utiliser KraftInk

Retrouvez les étapes pour installer KraftInk, configurer votre site et le gérer au quotidien.

- [Installer KraftInk](installation.md), puis [configurer le domaine et les e-mails](configuration.md).
- [Ajouter des plugins et des thèmes](extensions-catalogue.md), ou [importer un ancien site](migration.md).
- [Ajouter des images à la médiathèque](configuration.md#images-et-mediatheque).
- [Personnaliser le référencement et les aperçus de partage](seo.md).
- Relier un [serveur de jeu](games.md), des [connexions externes](oauth.md), les [paiements](shop-administration.md) ou les [votes](vote.md).
- Suivre les [statistiques](stats.md) ou proposer des [skins et capes Minecraft](skins.md).
- Préparer les [tâches automatiques et sauvegardes](operations.md), puis [mettre le site à jour](updates.md).

Pour créer un plugin, un thème de site, un thème d’administration ou un module de jeu, suivez le [guide développeur](developpeurs.md).
