# Game, identities and servers

Select a game in **Games and identities**. Only one game is active at a time. Switching keeps previous identities without converting them.

## Verifying identities

| Game | Verification |
| --- | --- |
| Minecraft Java | Mojang lookup checks profile existence. Ownership verification requires a Microsoft application and linking from the member’s account |
| Geyser/Floodgate | Enable compatibility and match the server’s `username-prefix`. Lookup does not prove Xbox ownership |
| Steam games | Enable Steam in external connections. OpenID verifies the account, not game ownership. FiveM uses the Steam identity here |
| Hytale | Declared profile. PlayerDB and Crafthead avatars are optional third-party services |

External avatars receive the player’s public identifier and their browser’s IP address. A member-uploaded image takes priority when allowed.

## Connecting a server

For Minecraft or Hytale using the connector, follow [KraftLink](kraftlink.md). For other modes, enable the service on the game server first. In **Game servers**, select the connection mode and save the server address. For RCON and other consoles, continue to **Manage connection** to enter settings and credentials. Ping is configured directly in the server record.

| Server | Prepare on the game server |
| --- | --- |
| Minecraft Java | Game port for status, with `enable-rcon`, `rcon.port` and `rcon.password` for RCON, or [KraftLink](kraftlink.md) for deliveries requiring player presence |
| Garry’s Mod, CS2, TF2, ARK: Survival Evolved, Project Zomboid | A2S UDP query port and enabled Source RCON TCP console |
| Unturned | A2S port and a server component compatible with Source RCON |
| Rust | A2S port and WebRCON with `rcon.web 1` |
| DayZ | A2S port and BattlEye RCON UDP console |
| 7 Days to Die | A2S port and password-protected Telnet console |
| FiveM, RedM | FXServer port for `dynamic.json` and `rcon_password` for commands |
| ARK: Survival Ascended | `RCONEnabled`, `RCONPort` and `ServerAdminPassword` in `GameUserSettings.ini` |
| Conan Exiles | Query port and `[RconPlugin]` section with RCON enabled, its port and password |
| Palworld | `RESTAPIEnabled`, REST port and administrator password |
| Satisfactory | HTTPS API and a token generated by `server.GenerateAPIToken` |
| Hytale | [KraftLink](kraftlink.md), with a compatible server version |

Game, query and console ports may differ. Allow the required protocols in the firewall. An unencrypted console needs a trusted network or tunnel.

Enter the actual host and ports, SRV records are not followed. For a private address, the hosting manager must allow its network in `config/games.php` under `network.private_cidrs`.

For Palworld HTTPS or Satisfactory with a private certificate, place its `.pem` CA in `storage/app/private/game-certificates/` and enter its name in **Manage connection**.

### WebRCON for Rust

In **Manage connection**, **WebRCON protocol** defaults to **WS (unencrypted)**. If the Rust server or its proxy offers encrypted WebRCON access, select **WSS (TLS)** and enter its port.

If the console uses a different address, enter its hostname in **WebRCON host (optional)**. If you leave the field blank, KraftInk uses the hostname in the server record. The public game address and A2S queries use the hostname in the server record in both cases.

In **WSS (TLS)** mode, the certificate must be trusted by the KraftInk host and match the WebRCON hostname. A valid public certificate is verified automatically. If the connection fails, KraftInk reports the error and keeps the encrypted mode.

## Testing commands

A correct public status does not validate console access. Try a harmless command before rewards and set up [cron](operations.md#scheduler) for status updates and deferred deliveries.

Waiting for a player requires presence evidence from KraftLink or the supported authenticated interfaces of Palworld and ARK: Survival Ascended. Available commands depend on the server and its plugins. The native Palworld API cannot distribute arbitrary items without another integration.
