# Configure the game and servers

Choose your community’s game under **Games and identities**, then add its servers under **Servers**. Only one game is active at a time. Switching games preserves previous identities and connections without converting them to the new game.

## Games included with KraftInk

KraftInk includes modules for **17 games**: Minecraft, Hytale, Garry’s Mod, Rust, FiveM, DayZ, ARK: Survival Evolved, 7 Days to Die, Counter-Strike 2, Team Fortress 2, Unturned, Project Zomboid, RedM, ARK: Survival Ascended, Palworld, Satisfactory and Conan Exiles.

The module defines player identifiers and available connection methods. Account verification, avatars, server status and remote commands depend on the game and configured connection. KraftLink is the dedicated connector for Minecraft and Hytale, rather than a requirement for every game.

## Choose player verification

A declared profile or a profile found in a public directory does not prove ownership. Before requiring verified identity to access the website, verify your own account and test the process with a member.

For **Minecraft**, checking that a Mojang profile exists and proving ownership with Microsoft are different rules. The latter requires a [configured Microsoft application](oauth.md), followed by linking the profile from the member’s account. Generic Microsoft sign-in alone does not prove game ownership.

For **Geyser/Floodgate** players, enable compatibility and match Floodgate’s `username-prefix` exactly: dot, plus or hyphen. Bedrock names use that prefix, with spaces replaced by underscores. This public lookup does not prove Xbox account ownership or replace Minecraft Java verification. With Global Linking, use the profile actually presented to the server.

For compatible **Steam** games, enable the provider under **External connections**. OpenID verifies the account without an application key. An optional Web API key retrieves public names and avatars. Steam does not return an email address, and signing in does not prove game ownership. FiveM uses Steam identity here. Cfx.re or Rockstar identifiers need a dedicated integration.

For **Hytale**, the profile remains declared. PlayerDB lookup and Crafthead avatars are optional third-party services enabled separately. Other games require the platform identifier indicated in the form. An RP character name or free display name does not replace it.

Avatar providers are optional. They receive the player’s public identifier and the browser’s IP address. A member-uploaded image takes priority when allowed.

## Prepare the server connection

The website’s game module does not enable the game server’s remote console. Configure it with your host first, then enter its ports and credentials in KraftInk.

| Server | Prepare on the game server |
| --- | --- |
| Minecraft Java | Game port for status, with `enable-rcon`, `rcon.port` and `rcon.password` for RCON, or [KraftLink](kraftlink.md) for deliveries requiring player presence |
| Garry’s Mod, CS2, TF2, ARK: Survival Evolved, Project Zomboid | A2S UDP query port and enabled Source RCON TCP console |
| Unturned | A2S port and a server component compatible with Source RCON |
| Rust | A2S port and WebRCON with `rcon.web 1` |
| DayZ | A2S port and BattlEye RCON UDP console |
| 7 Days to Die | A2S port and password-protected Telnet console |
| FiveM, RedM | FXServer port for `dynamic.json` and `rcon_password` for commands |
| ARK: Survival Ascended | `RCONEnabled`, `RCONPort` and `ServerAdminPassword` in `GameUserSettings.ini` |
| Conan Exiles | Query port and `[RconPlugin]` section with RCON enabled, its port and password |
| Palworld | `RESTAPIEnabled`, REST port and administrator password |
| Satisfactory | HTTPS API and a token generated by `server.GenerateAPIToken` |
| Hytale | [KraftLink](kraftlink.md), with a compatible server version |

Game, query and console ports may differ. Allow the required protocols through the firewall, ideally only from the website’s host. Unencrypted consoles should use a trusted network or tunnel.

Enter the real hostname and ports: SRV records are not followed. Private addresses are blocked by default. For an internal network, have only the necessary address or CIDR added to `config/games.php`, key `network.private_cidrs`.

For Palworld HTTPS and Satisfactory, a private certificate can be trusted by placing its CA `.pem` in `storage/app/private/game-certificates/`, then entering its filename in the server configuration. The certificate must match the hostname. Keep TLS verification enabled.

## Test before offering rewards

Check server status, then a harmless command with your configuration. A working public status check does not validate console credentials. [Scheduled tasks](operations.md) must run to update status and process commands.

A command requiring a player to be online needs a connection that can confirm their presence: KraftLink for Minecraft/Hytale, or the compatible authenticated interfaces of Palworld and ARK: Survival Ascended. A player count or ordinary RCON response is not enough.

Adapt rewards to the commands actually available. For example, Palworld’s native API cannot distribute arbitrary items: that needs a suitable mod or connector. On RP servers, also check that the command targets the correct account or character.

If a command needs review after a network interruption, check the game logs before retrying: it may already have taken effect.
